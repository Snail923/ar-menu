Connect publishing

One time on this device: paste the GitHub access token for the menu's repository. The menu is saved there.

How do I get a token?
  1. Open GitHub → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → the menu repository.
  3. Permissions → Contents: Read and write. Leave everything else as it is.
  4. Generate, copy the token and paste it above. Share it only with people who should edit the menu.
